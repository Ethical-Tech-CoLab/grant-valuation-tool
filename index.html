What it does

🔎

Web prospecting & import

Paste a grant URL or a search query — the web is scraped and Claude structures it into grant fields that pre-fill the form.

📊

AI-assisted scoring

Claude values each grant against the ETC mission: a 0–100 fit score, win probability, expected value, red flags, and a pursue / consider / pass call.

✍️

Tailored proposal draft

One click turns a grant into an initial proposal: a title, core thesis, an outline, how ETC maps to the funder's criteria, and gaps to shore up.

🎯

Funder review criteria

Capture how the funder scores applications — their rubric and weights — and feed it into both the scorer and the proposal so you write to what wins.

🗂️

Pipeline & deadlines

Every opportunity moves through six stages on a board view, with due-soon flags and an upcoming-deadlines panel.

✅

Priority actions digest

A cross-pipeline, deadline-aware to-do list that finds each active grant's most pressing gap and ranks them — so the team always knows what's next.

Run the full tool

This page is a static overview. The full tool — AI scoring, web import, and proposal drafting — runs as a Next.js app that needs a server and an ANTHROPIC_API_KEY. Clone the repository, then npm install and npm run dev to run it locally, or deploy it to a Node host such as Vercel.
